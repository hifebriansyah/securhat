Situs ini

securhat.com adalah halaman perkenalan statis. Tidak ada akun, formulir, atau kolom komentar di sini, dan halaman ini tidak memasang cookie sendiri.

Siapa yang memprosesnya

Situs ini dihosting di GitHub Pages. Seperti server web pada umumnya, penyedia hosting dan jaringan pengiriman konten (seperti GitHub atau Cloudflare) mencatat data teknis permintaan, misalnya alamat IP, jenis browser, dan waktu akses, untuk menjalankan dan mengamankan layanan. Kami tidak memakai data itu untuk melacak kamu.

Omon Omon

Aplikasi Omon Omon di omonomon.securhat.com punya kebijakan privasinya sendiri di halaman privasi Omon Omon: apa yang disimpan di browser-mu, siapa yang memproses pesanmu, dan cara menghapus datamu.

Iklan

Situs Securhat, termasuk subdomainnya, dapat menampilkan iklan dari pihak ketiga seperti Google AdSense. Google dan mitranya dapat memakai cookie atau teknologi serupa untuk menayangkan dan mengukur iklan. Di Omon Omon, iklan baru dimuat setelah kamu mengizinkannya dan pilihan itu bisa diubah kapan saja. Kamu juga bisa mengatur iklan Google di adssettings.google.com, dan membaca cara Google memakai data di policies.google.com/technologies/ads.

Anak-anak

Situs ini tidak ditujukan untuk anak kecil. Jika kamu menduga seorang anak telah membagikan data pribadi kepada kami, hubungi kami dan kami akan menghapusnya.
